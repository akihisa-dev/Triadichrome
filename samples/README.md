# 全機能確認用の計画

`npm run samples:generate`でローカルに生成する`全機能確認用.triadic`はアプリ8.0.0の実装に対応した、基準年度2026・保存形式16の確認用データです。生成元は[tests/ui/sample-plan.ts](../tests/ui/sample-plan.ts)、再生成・一致確認は[README](../README.md#確認用のtriadicファイル)を参照してください。生成ファイルはGit管理せず、GitHubへアップロードしません。実ファイルの上書きを避けるため、試す際はコピーを使用します。

1,014施策・12,032科目行・両予算と前年で289,704件分の月別金額を含む大規模サンプルです。元の14施策に「大規模確認施策0001」から「大規模確認施策1000」を追加しています。各追加施策は12科目行を持ち、一次予算の金額と確定予算の手修正を正負の対で相殺します。全展開・業種・部署に分散し、両種別の開始年月は2026-04です。既存の確認用金額と未使用科目は維持します。3時点の履歴にも1,014施策を保持します。

通常の画面テストは元の14施策を使用します。実ファイルと同じ規模は画面テスト入口の「大規模全機能確認用」または`?data=large`で選択できます。

金額はすべて千円単位です。たとえば「既存商品の販売拡大」の一次予算4月は120千円（120,000円）です。小数0.001は1円を表し、表示は整数千円に丸めます。

## 開始年月の確認

通常の非0施策は「新規」、前年開始の専用施策だけは「期間差」を指定しています。開始年月が空欄なのは、全月0の「未確定施策の入力準備」「科目変更と削除の確認」の2件です。金額がないため開始月を確定できず、4月などへ金額を入力すると自動算出されます。

| 施策 | 一次予算の開始年月 | 確定予算の開始年月 |
|---|---|---|
| 既存商品の販売拡大・通信運搬費と消耗品費の削減・サブスクリプション事業の拡大・確定予算の手修正・確定予算の下期調整・確定予算のゼロ固定 | 2026-04 | 2026-04 |
| 季節キャンペーン・ゼロと相殺の確認 | 2026-05 | 2026-05 |
| 保守サービスの新規契約 | 2026-07 | 2026-08 |
| 設備更新と償却費の見直し・助成金の受入れ | 2026-09 | 2026-09 |
| 期間差の開始年月確認 | 2025-10 | 2025-11 |
| 未確定施策の入力準備・科目変更と削除の確認 | 空欄 | 空欄 |

元の14施策の両種別の開始年月は通常テストで照合します。期間と備考以外の金額・行・分類・履歴の確認範囲は上記の対応表に従います。

「保守サービスの新規契約」は一次予算が2026-07、確定予算が2026-08です。施策一覧の種別を切り替え、施策名の隣の開始年月が切り替わることを確認します。

「期間差の開始年月確認」は一次予算が2025-10、確定予算が2025-11です。正負の2行が相殺して売上合計は0でも開始年月を表示します。一次予算の10月に非0の金額を入れると開始年月は2025-11へ変わります。4〜9月の途中を全行0にしても継続とみなし開始年月を維持します。4月を全行0にした場合や3月に非0の金額を入れた場合は空欄になります。「未確定施策の入力準備」は開始年月が空欄です。開始年月は直接編集できません。

## 履歴の確認

「既存商品の販売拡大」の一次予算4月を120から130へ変更し、保存後に共通ヘッダーの「操作を取り消す」で120、「操作をやり直す」で130へ戻ることを確認します。確定予算4月の手修正130と11月の手修正0はどちらの操作でも残ります。取り消し後に一次予算4月を140へ変更すると、やり直しはできなくなります。削除確認用科目の削除と取り消し、前年金額の編集と取り消しも試せます。操作履歴はこのファイルを開いてからの保存成功分だけを保持し、開いた直後は空です。

主ファイルには3時点の履歴があります。「履歴」の最古の日時を選ぶと「既存商品の販売拡大」の1行目・一次予算4月は100、備考は「履歴確認用の過去の状態」です。次の日時は110、現在は120です。全種別の手修正・前年実額・マスタも各時点に含まれます。

## 種別変更の確認

総原価表・展開表は初期値が一次予算・未選択です。選択は画面ごとに保存します。展開表4月の一次予算は展開計の売上415、合計の売上20,757.25、利益17,290.125です。表示時だけ整数千円へ丸めます。確認用データには確定予算の全月引き継ぎ、4月の手修正、5月と11月の手修正0、10月の下期調整を含めています。旧形式拒否、重複選択拒否、選択の保存失敗は自動テストと模擬ファイルで確認します。

## Excel入出力の確認

「入出力」で三表の一表・二表・三表の組み合わせ、種別と比較対象を指定して出力します。画面の行順・期間見出し・0の非表示・比較差を確認し、「計算元」の金額を編集すると小計・合計・利益率が再計算されることを確認します。通常画面の選択は変わりません。

前年入力は直営自動車・部署Aと自動車取扱・部署Bなど必要な組み合わせだけを選びます。各シートの4月を空欄、5月を0、6月を-123.456にして取り込み、4月を保持して5月・6月だけが変更一覧に出ることを確認します。確定後は前年入力・三表へ反映し、操作の取り消しで一括して元に戻せます。小数4桁・文字・数式・科目名や月見出しの変更は拒否し、計画を変更しません。保存失敗は確認用画面の模擬保存で試し、現在データと変更一覧が残ることを確認します。

科目属性マスタは「マスタ」またはホームの相関図から開き、売上・売上原価・費用・利益の4件と名称が固定され、追加・編集・削除の操作がないことを確認します。勘定科目マスタの科目行の選択候補と一致し、集計はこのマスタに含みません。

金額項目マスタでは、表示順1〜3と売上・費用・利益の3件、科目属性の構成（売上−売上原価、費用、売上−売上原価−費用＋利益）を確認します。追加・編集・削除の操作はなく、マスタ入口とホームの相関図の両方から開けます。

施策入力の合計欄は金額項目マスタに従う3行です。「既存商品の販売拡大」の一次予算4月は売上90・費用11・利益79（計算値79.125）、確定予算4月の売上は100です。入力や種別変更への追従、入力行がなくても3行の0を表示することを確認します。
