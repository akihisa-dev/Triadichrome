# 入出力の設計と実装計画

## 操作と結果

サイドバーの「入出力」でExcel形式の出力と前年実額の取り込みを行う。総原価表・展開表・施策一覧を一つ以上選び、一つのファイルの別シートへ出力する。種別と比較対象は表ごとに指定し、総原価表だけ業種・部署で絞り込める。条件は画面内に保持し、通常の各表の表示設定や計画ファイルへ保存しない。

表の行順、月・四半期・半期・年間の列順、結合見出し、罫線、背景、文字と列幅を画面に合わせる。Excelの表示形式で千円の整数と利益率を表示し、元の金額の小数を保持する。小計、合計、比較、期間計と利益率は数式にする。必要な計算元を「計算元」シートにまとめ、独立して選んだ表にも有効な参照を持たせる。Excelでの編集結果をアプリへ取り込む対象は前年入力フォーマットだけとする。

前年入力フォーマットでは業種・部署の組み合わせを複数選択できる。選んだ組み合わせごとに別シートを作り、科目コード・科目名を縦、4月〜3月を横に配置して現在の前年実額を入れる。金額は千円単位で小数点以下3桁まで。識別情報と元の金額は非表示の管理シートに保持する。

取り込みではフォーマット、年度、業種・部署、科目と月を検証する。数式セルは取り込み対象にせず、数値または数値文字列を受け付ける。空欄は更新せず、0は更新する。シートの欠落、重複、不正値や識別情報の変更はファイル全体を拒否する。出力後に変わった前年金額との競合も拒否する。変更一覧に分類・科目・月・変更前後を表示し、利用者の確定後に一回の保存で反映する。保存失敗では一覧と現在データを保ち、再試行できる。取り消し・やり直しと時点履歴には既存の保存経路で接続する。過去閲覧では出力だけ許可する。

## 実装の分担と順序

1. `core/spreadsheets`にExcelの表生成・フォーマット読取を置く。ExcelJSを固定版で追加し、端末内だけで処理する。
2. `core/storage`に前年の差分を一括検証・保存する処理を追加する。既存の命令・保存・履歴経路へ接続する。
3. `extension`に入出力画面、分類の組み合わせ選択、確認一覧、ファイル選択とダウンロードを追加する。
4. 要件・README・画面とデータ・計算と処理の説明・確認用データを更新する。
5. 全7通りの表選択、比較順序、数式・表示精度、フォーマット往復、空欄と0、不正入力・競合・失敗時の保護を自動テストで確認する。Codex内ブラウザで表示と操作を確認し、標準検証後に通常コミットする。

## 境界

通信・Chrome権限・保存形式の変更は行わない。取り込みファイルは処理中だけメモリに持ち、キャンセルや画面終了で解放する。出力はダウンロードで、開いている`.triadic`ファイルを書き換えない。Excelでの再計算はExcel側に委ね、出力時点の計算結果も保存する。

配布物のJavaScriptでは、テンプレート文字列を通常の文字列へ変換し、文字列内の改行をエスケープする。ExcelJSを同梱した生成物にも差分検査を適用できるようにし、文字列の値は変更しない。
