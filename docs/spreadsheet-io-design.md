# 入出力の設計

## 操作と結果

サイドバーの「入出力」でExcel形式の出力と前年実額の取り込みを行う。総原価表・展開表・施策一覧を一つ以上選び、一つのファイルの別シートへ出力する。種別と比較対象は表ごとに指定し、総原価表だけ業種・部署で絞り込める。条件は画面内に保持し、通常の各表の表示設定や計画ファイルへ保存しない。

三表の出力はMicrosoft 365向けとし、計画全体の前年金額・一次予算・確定予算の手修正・全施策・全マスタを含める。表の選択と条件は表示にだけ適用し、元データを削らない。表示する表と比較列の数・種別は出力時の指定を維持する。総原価表の対象は業種・部署マスタの「総原価対象」で変更できる。

入力と表示を分け、施策入力、施策金額、前年金額、科目・集計・分類マスタ、集計対象、総原価行順をExcelテーブルにする。新しい施策は施策IDを一つ追加し、そのIDを持つ科目行を施策金額へ追加する。参照中のIDは維持し、名称とコードは変更できる。確定予算の修正は空欄で引き継ぎ、0を含む数値で固定する。開始年月規則は保存されている規則を出力し、期間名の改名後も維持する。

科目別の集計は列と条件を指定するSUMIFS、属性別の売上・費用・利益はSUMPRODUCTで求める。集計対象テーブルの子科目・子集計と符号を名前付き数式で読み、入れ子を計算する。未設定の子を含む集計は「未設定」、循環や参照エラーはエラーを表示する。表示列の式は名前付きの月次・期間・差額計算を呼び出し、入力行数に比例して式を長くしない。期間計の利益率は期間の利益÷売上から求め、月の率を足さない。

Microsoft 365の配列数式で表示行を増減させる。総原価行順は既存の配置を保持し、新しい科目・集計を末尾へ自動追加する。行順テーブルへ項目を追加すれば位置を変更できる。展開表は展開コード順に施策と小計を組み立てる。本文の結合を使わず、展開名を各行に表示する。月・四半期・半期・年間の列順、見出しの結合、罫線、列幅・背景・表示精度は維持する。Excelでの編集結果をアプリへ取り込む対象は前年入力フォーマットだけとする。

前年入力フォーマットでは業種・部署の組み合わせを複数選択できる。選んだ組み合わせごとに別シートを作り、科目コード・科目名を縦、4月〜3月を横に配置して現在の前年実額を入れる。金額は千円単位で小数点以下3桁まで。識別情報と元の金額は非表示の管理シートに保持する。

取り込みではフォーマット、年度、業種・部署、科目と月を検証する。数式セルは取り込み対象にせず、数値または数値文字列を受け付ける。空欄は更新せず、0は更新する。シートの欠落、重複、不正値や識別情報の変更はファイル全体を拒否する。出力後に変わった前年金額との競合も拒否する。変更一覧に分類・科目・月・変更前後を表示し、利用者の確定後に一回の保存で反映する。保存失敗では一覧と現在データを保ち、再試行できる。取り消し・やり直しと時点履歴には既存の保存経路で接続する。過去閲覧では出力だけ許可する。

## 実装と検証

`core/spreadsheets/reportWorkbook.ts`が三表と入力テーブルを、`workbook.ts`が前年フォーマットと取り込みを所有する。`xlsxFormulaSupport.ts`はExcelJSが生成しない計算列の数式、名前付き数式、配列数式の管理情報を標準のExcelファイルへ追加する。計算列の定義をテーブルに持たせ、末尾の行追加でも確定予算の引き継ぎと参照の式を継続する。入力規則は既存テーブル行へ設定し、Excelの行挿入で引き継ぐ。

自動テストは全7通りの表選択、種別の単独・両方・逆順、分類条件、元データの完全性、保存前後の数式と管理情報を確認する。保存済み結果を使わないテスト用の数式評価器で出力直後をアプリと照合し、元データ変更・修正0と解除・施策と科目の追加・分類と名称と集計の変更を再評価する。空の計画、未設定集計、開始年月と相殺、前年入力の往復・不正入力・競合・保存失敗も確認する。

ExcelJS 4.4.0の読み取り処理には計算列を含むテーブルを解釈できない制限がある。テストの読取用コピーでは計算列の管理要素だけを外し、元ファイルの管理要素と数式は別途検証する。配布するファイルからは削除しない。これらの自動テストはMicrosoft 365のExcel実機での再計算を代替しない。Codex内ブラウザで入出力画面と操作を確認し、標準検証後に通常コミットする。

## 境界

通信・Chrome権限・保存形式の変更は行わない。取り込みファイルは処理中だけメモリに持ち、キャンセルや画面終了で解放する。出力はダウンロードで、開いている`.triadic`ファイルを書き換えない。Excelでの再計算はExcel側に委ね、出力時点の計算結果も保存する。

配布物のJavaScriptでは、テンプレート文字列を通常の文字列へ変換し、文字列内の改行をエスケープする。ExcelJSを同梱した生成物にも差分検査を適用できるようにし、文字列の値は変更しない。
